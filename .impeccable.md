## Design Context

### Users
Photographers using the desktop repository with Codex, Claude Code or a terminal. They need to inspect the actual Best, Series and Sequence produced from their photo folder, without building an app or running a server.

### Brand Personality
Quiet, clear, photographic. The result should be easy to assess, and the photographer's intention and corrections remain authoritative.

### Aesthetic Direction
The initial gallery uses a light editorial contact-sheet direction. This is an implementation choice to assess with photographers, not a recorded user preference. Large uncropped photographs, warm paper, dark readable captions, restrained rules, generous space. Offline system serif/sans stacks; no remote fonts or assets.

### Design Principles
- The photographs lead; interface decoration stays restrained.
- Preserve the exact validated selection and order, including deliberate repeated images across sections.
- Explain the selection in plain language; keep technical metadata out of the viewing flow.
- Work directly from a local file and remain useful when the result folder moves.
- Respect keyboard navigation, browser zoom, reduced motion and accessible contrast.
