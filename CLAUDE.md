# Dial In

Read and follow `AGENTS.md`, then use `docs/AGENT-WORKFLOW.md` for photography tasks.
The default product is a desktop CLI with independent components, used from this repository.
Start with `node scripts/dialin.mjs --help` and the relevant `doctor` check. No iPhone app is required.
Contributor checks: `npm test` (offline; no camera, radio or paid model call).
